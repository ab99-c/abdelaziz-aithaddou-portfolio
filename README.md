# Abdelaziz Aithaddou — Portfolio

Personal portfolio website for Abdelaziz Aithaddou, a Moroccan software founder and full-stack developer.

## Run locally

This is a static site. Serve the project directory with any static server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Notes

- Arabic is the default language, with an English toggle.
- The site is responsive and requires no build step.
- Update the contact CTA once the preferred email or social link is available.
